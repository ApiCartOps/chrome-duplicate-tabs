Chrome Extension Test Page

Purpose: This page helps you test the "Group Tabs by Domain" Chrome extension.

Testing Instructions:

  1. Make sure the extension is loaded in Chrome (chrome://extensions/)
  2. Click the buttons below to open multiple test tabs from different domains
  3. Click the extension icon in the toolbar
  4. Click "Group Tabs by Domain" button in the popup
  5. Verify that tabs are grouped by their domain names
