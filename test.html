🔍 Duplicate Tabs Manager - Test Page

How to Test the Extension

Step 1: Install the extension
  • Open Chrome and go to chrome://extensions/
  • Enable "Developer mode" (toggle in top right)
  • Click "Load unpacked"
  • Select the extension directory
Step 2: Create duplicate tabs for testing
  • Open this page in multiple tabs (Ctrl/Cmd + Click the tab)
  • Open any other website in multiple tabs
  • For example, open Google.com in 2-3 tabs
Step 3: Test the extension
  • Click the extension icon in the toolbar
  • The popup will automatically scan for duplicates
  • Review the list of duplicate tabs
  • Click "Download CSV" to export the list
💡 Note: The CSV file will include:
  • URL of each duplicate tab
  • Title of each tab
  • Tab ID (Chrome internal identifier)
  • Window ID (which window the tab is in)
  • Duplicate Count (how many tabs have the same URL)

Expected CSV Format

URL,Title,Tab ID,Window ID,Duplicate Count
